# orchestrion

Generated files that support [Orchestrion](https://github.com/DataDog/orchestrion) compile-time
auto-instrumentation. For how Orchestrion works and how to add support for it to an integration, see
[contrib/ORCHESTRION.md](../contrib/ORCHESTRION.md).

## Contents

- [`all/`](./all) is the `github.com/DataDog/dd-trace-go/orchestrion/all` module. A project that
  imports it in its `orchestrion.tool.go` enables every dd-trace-go integration that supports
  Orchestrion, instead of importing each one individually.
- `all/orchestrion.tool.go` and `all/go.mod` are generated by `internal/orchestrion/generator`, which
  walks the repo and adds an import for every package that has an `orchestrion.yml`. Do not edit them
  by hand.
- `orchestrion.go` and `orchestrion.tool.go` are housekeeping files for this package, not integration
  code.

## Adding a new integration aspect

Adding or changing a contrib's `orchestrion.yml` does not update `all/` on its own. Run
`make generate` to regenerate `all/orchestrion.tool.go` and `all/go.mod`; CI's Generate Check fails if
they are out of date.
